Environmental pollution is a major problem that 
affects air, water and land. Monitoring these changes is important 
for effective planning and mitigation. In this paper, we present 
“Pollution Detection Using Satellite Images”, a web-based 
environmental monitoring system that studies air, water and land 
pollution using satellite data. The system uses Google Earth Engine 
and satellite sources such as Sentinel-5P, Sentinel-2, Landsat and 
MODIS to collect and understand environmental indicators. It 
examines air indicators like NO₂, SO₂, CO, O₃, CH₄ and HCHO, 
along with aerosol-related information, water indicators like NDWI 
and MNDWI, and land indicators like NDVI, NDBI and BSI. Users 
can search for any location across the globe and get these metrics. 
They can then get detailed reports explaining these metrics and their 
impact with the help of a Large Language Model. This system also 
allows users to see time-series graphs to understand historical data, 
predict future pollution levels using Random Forest, XGBoost and 
LightGBM machine learning algorithms, and identify pollution 
hotspots using DBSCAN. By combining satellite data, spatial 
analysis, hotspot detection and data visualization, our proposed 
system provides a common platform to study environmental 
conditions across different locations efficiently and makes 
monitoring easy.
